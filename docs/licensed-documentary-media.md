## Active, reusable documentary photographs (Wikimedia Commons)

All active homepage photographs below depict real named Koperasi Desa/Kelurahan Merah Putih buildings. The image entries in `src/data/visual-media.ts` include the author, Commons file page, license URL, location, alt text and browser crop position. These **replace** previously used publisher photographs whose redistribution terms were uncertain. The original Wikimedia thumbnail URLs are retained as source metadata; ten optimized WebP renditions have been committed under `public/images/documentary/`.
