# Active KOPDES media credits

The homepage uses photographs of five distinct real Koperasi Merah Putih buildings. They are **not** branches operated by this independent informational site. The WebP files in `public/images/documentary/` were converted from Wikimedia thumbnails using Sharp: resized (640px / up to 1280px), compressed, format-converted, orientation normalized if needed; no scene content was deliberately altered. Those changes must be disclosed on redistribution.
