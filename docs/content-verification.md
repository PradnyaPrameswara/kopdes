# Content and identity verification gate

This repository is an **independent visual/informational concept**, not the website of a specific registered Koperasi Desa/Kelurahan Merah Putih and not an official government portal.

PR #13 removes sample legal/operational assertions from rendered pages:
- Fake office address in Desa Makmur, sample phone and WhatsApp, and purported official socials.
- Claims of 1,200 members, Rp2.4B distribution, active branches, opening hours, 24/7 clinic, subsidies, fixed member contributions and automatic SHU.
- Unverified Presidential quotation attributed to Prabowo.
- Unverified branch badges; service cards now describe **potential kinds of units**, not operating locations.
- /daftar remains guidance-only and collects no NIK.

For public use, a cooperative operator must independently provide **written verification** of legal name, physical branches, operating hours, membership process, payment terms, imagery rights, brand/portrait usage, and authorized contact channels. Restore verified details intentionally—not via mock data. Every documentary photo must retain true publisher/location credit.

Official program sources (not endorsements of this website):
- Kemenkop JDIH Implementation Guide 1/2025: https://jdih.kop.go.id/doc/detail/doc-1168-v_peraturan
- Kemenkop public portal: https://simkopdes.go.id/
